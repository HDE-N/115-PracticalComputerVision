# 115-基於目標檢測與人體骨架關鍵點融合之異常行為識別系統

## 摘要

本專題以考場監考為應用場景，建立一套結合**目標檢測（Object Detection）**、**人體骨架關鍵點（Pose Estimation）**與**多視角融合（Multi-View Fusion）**的異常姿勢識別**系統框架**。
系統在考場架設 3–4 台固定攝影機，沿用課程的多相機標定流程（[1151125_3D稀疏點雲](../1151125_3D稀疏點雲/)）取得各鏡頭內外參。由於考生座位固定，系統事先建立「座位地圖」，以**座位編號**作為考生身分；各鏡頭偵測人員與骨架關鍵點、偵測手機等可疑物品後，以座位為單位融合多個視角，再交由可插拔的規則模組判斷異常姿勢，最後即時告警並保存影片作為佐證。
本期以「**端到端可運作、模組可替換、資料可累積**」為目標，準確度只求可展示的基準水準；自訓練物品模型、3D 骨架、學習式行為分類等進階功能，保留介面留待後續延續。

**關鍵字**：YOLO、骨架關鍵點、多相機標定、多視角融合、異常姿勢識別、模組化框架、考場監控

---

## 動機

近期考場作弊日漸猖獗，此舉除了讓認真準備的學生心寒外，也讓考試失去鑑別度與意義。當前考場抓作弊所面臨之困境如下：

1. **監考人員注意力有限**：監考人員的視角難以全程覆蓋整間考場，且長時間監考容易疲勞、分心。
2. **證據不足**：即便當場發現作弊，若無影像佐證，作弊學生極可能以「證據不足」申訴成功。
3. **同學包庇問題**：許多人其實知道有人作弊，但礙於同儕關係，大部分情況下會選擇沉默。

若能由系統「客觀、全程、不疲勞、多角度」地輔助監看，並在疑似異常時自動留存證據，便能補足上述缺口。綜上所述，本專案具備實務上之需求。

> 定位：本系統為**輔助工具**，只負責「提醒」與「留證」，最終是否作弊仍由監考人員判定，不由系統直接定罪。

     └───────────┬───────────┘

## 框架設計

### 共用資料格式（模組之間只透過這些結構溝通）

| 結構 | 內容 | 產生者 → 使用者 |
|------|------|----------------|
| `FrameBundle` | 時間戳、`{cam_id: image}` | 擷取 → 各偵測模組 |
| `SeatObservation` | `cam_id, seat_id, person_bbox, keypoints[17×3], objects[]` | 偵測模組 → 融合 |
| `SeatState` | `seat_id, 時間戳, 融合後特徵 dict, 參與的鏡頭` | 融合 → 規則引擎 |
| `Event` | `seat_id, 行為代號, 開始/結束時間, 分數, 鏡頭, 影片路徑` | 規則引擎 → 告警 / 存證 |

### 模組介面（抽象類別，方便日後替換）

```python
class PersonDetector:    def detect(self, image) -> list[BBox]
class PoseEstimator:     def estimate(self, image, bboxes) -> list[Keypoints]
class ObjectDetector:    def detect(self, image) -> list[Object]
class MultiViewFusion:   def fuse(self, obs: list[SeatObservation]) -> list[SeatState]
class BehaviorRule:      # 每種異常行為一個子類別
    code: str            # 例如 "A1"
    def check(self, state: SeatState) -> float   # 回傳 0~1 觸發程度
class AlertSink:         def emit(self, event: Event)  # 畫面 / 聲音 / 檔案 / 推播
```

- **規則註冊**：`config/rules.yaml` 決定啟用哪些規則及門檻、權重；新增行為 = 新增一個 `BehaviorRule` 子類別 + 設定檔加一段。
- **設定檔驅動**：鏡頭、模型路徑、門檻全部寫在 `config/`，換場地或換模型不改程式。
- **離線 / 即時雙模式**：`--source camera` 或 `--source data/recordings/session_001/`，開發與評估都用錄影，結果可重現。
- **特徵紀錄**：每幀 `SeatState` 寫入 `output/features/*.parquet`（或 csv），後續可直接拿來訓練學習式分類器。

## 方法

### 0. 前置作業：鏡頭擺放、標定與座位地圖

1. **擺位**：4 台鏡頭架高（約 2.2–2.5 m），放在教室前方左右兩角與後方左右兩角，俯角約 30°–45°；
   只有 3 台時改成前方左右各 1 台 + 後方中間 1 台。確認每個座位至少被 2 台看到上半身後再固定。
2. **標定**：沿用 [1151125_3D稀疏點雲](../1151125_3D稀疏點雲/) 的 `camera_setup.py`（鎖定 3A）、`calib_intrinsic.py`、`calib_extrinsic.py`。
   建議標定時把 ChArUco 板平放在桌面當世界座標原點，方便日後擴充 3D 判斷。
3. **座位地圖**（`config/seats.yaml`）：每個座位在各鏡頭中的 ROI 與桌面線。
   - MVP：用 `seat_editor.py` 在每台鏡頭畫面上手動框選（最快、最穩）。
   - 進階：量測桌椅的世界座標，用投影矩陣 `P = K[R|t]` 自動投影到各鏡頭。

> 標定在 MVP 中主要供座位地圖投影與日後 3D 擴充使用；若時程緊，可先手動框選 ROI 讓系統跑起來，標定並行進行。

### 1. 人員辨識模組

- YOLO11x（`ultralytics`）COCO 預訓練，只保留 `person`。
- 以「人員 bbox 與座位 ROI 重疊度最大者」決定座位編號；座位編號即身分，跨鏡頭天然對齊。
- 座位 ROI 內找不到人 → 標記「座位無人」，供 A8 使用。

### 2. 骨架偵測模組（核心）

- YOLO11x-Pose 取得每人 17 個 2D 關鍵點與信心值。
- 計算基本特徵（以肩寬正規化，消除遠近差異）：
  - 頭部水平轉向：`(nose.x − ear_mid.x) / shoulder_width`
  - 手腕相對桌面線的高度、手腕是否超出自己座位 ROI
  - 肩膀中心高度（站起）
- 信心值過低的關鍵點視為遮擋，不參與判斷；特徵以移動平均做簡單平滑。

### 3. 物品偵測模組（輔助）

- MVP 直接用 COCO 預訓練模型的 `cell phone` 類別，不另外訓練。
- 手機 bbox 依座位 ROI 歸屬到座位，並判斷是否靠近手腕或臉部。
- 介面已預留，後續換成自訓練模型即可加入手錶、紙條等類別。

### 4. 多視角融合模組

- MVP：每個座位、每條規則，在各鏡頭各自計算觸發程度，取**最大值**（任一視角觸發即成立；寧可多報）或**多數決**（降低誤報），由設定檔切換。
- 後續：依各鏡頭對該座位的可見度加權；同一座位有 ≥ 2 視角時以 `cv2.triangulatePoints()` 求 3D 骨架，改在世界座標判斷。

### 5. 規則引擎

- 每條啟用的規則輸出觸發程度 `f_k ∈ [0, 1]`；
  座位異常分數 `S = Σ w_k · f_k`，並以時間累積（leaky bucket：觸發時累加、正常時緩慢遞減）。
- `S` 超過門檻 → 產生 `Event`；同一座位同一行為在冷卻時間內不重複告警。

### 6. 告警與證據模組

- **畫面**：OpenCV 2×2 拼接顯示所有鏡頭，框線、座位號、骨架、異常分數；告警座位框線變紅。
- **提示音**：告警時發出聲音。
- **存證**：每台鏡頭以環形緩衝區保留最近 N 秒影格，告警時保存事件前 5 秒 + 後 5 秒的多視角影片。
- **紀錄**：寫入 `output/events.csv`（時間、座位、行為代號、分數、鏡頭、影片路徑）。

## 實驗與評估

本期以「驗證框架可運作」為主，不追求高準確度：

1. **錄製測試影片**：同學在教室模擬考試（3–6 人），依 ★ 行為輪流演出，穿插正常動作（寫字、伸懶腰、撿筆、喝水），多鏡頭同步錄製約 10–15 分鐘，並簡單標註事件起訖時間。
2. **功能驗證**：逐項確認「驗收標準」表是否達成。
3. **基準數據**：用 `evaluate.py` 量測每種行為的事件級 Precision / Recall，以及單鏡頭 vs. 多鏡頭的差異，作為後續改進的比較基準。
4. **問題紀錄**：整理誤報 / 漏報的典型案例（例如撿筆被誤判為手伸桌下），作為後續延伸的改進方向。

## 預期困難與對策

| 困難 | 對策 |
|------|------|
| 時間只有 5–6 週 | 嚴守 MVP 範圍；先用錄影離線開發，最後再接即時鏡頭；全部使用預訓練模型，不訓練 |

## 後續延伸方向

依建議優先順序：

1. **補齊行為規則**：A2 回頭、A4 低頭、A7 看手錶。
2. **自訓練物品偵測**：以本期錄影標註手機、手錶、紙條，提升俯拍視角的偵測率。
3. **3D 骨架**：利用已完成的標定做多視角三角測量，在世界座標判斷手部高度、頭部朝向、手腕間距離。
4. **學習式行為分類**：以累積的骨架特徵序列訓練 LSTM / ST-GCN，取代或輔助規則。
5. **細部特徵**：MediaPipe Hands / Face Mesh 取得手指與精確頭部角度。
6. **實用化**：網頁監控介面、手機推播（Telegram / Discord）、事件回放、長時間穩定運行。
