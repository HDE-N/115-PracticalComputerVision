# 電腦視覺實務 — 作業備份

115 學年度「電腦視覺實務」課程的作業與課堂練習備份，每週的程式碼都會存放在這個倉庫。

## 課程主題
- 相機成像、座標系統與相機標定（棋盤格 / ChArUco）
- 對極幾何、基礎矩陣 / 本質矩陣、立體視覺標定
- 特徵點擷取與配對（SIFT、ORB、SURF）
- 多相機聯合標定、誤差傳播、光束法平差 (Bundle Adjustment)
- 三角測量與 3D 點雲重建
- 語意分割、實例分割

## 目錄結構
```
.
├── README.md
├── .gitignore
├── YYYMMDD_標題/        # 每週一個資料夾，YYY 為民國年（例：1151125_3D稀疏點雲）
│   ├── README.md        # 必寫：本週說明、輸入/輸出、如何被後續作業調用
│   ├── Task.md          # 本週作業題目與實作步驟
│   └── ...              # 程式碼、輸出結果
└── ...
```

## 每週資料夾規範
後面的作業常常要用到前幾週的結果（例如相機內外參、特徵點、點雲），
所以**每週的資料夾都必須附上 `README.md`**，讓之後可以快速查到、直接調用。內容至少要有：

```markdown
# YYYMMDD_標題

## 作業目標
一兩句話說明這週要做什麼。

## 依賴的前期結果
- 來源資料夾 / 檔案路徑（例：../1151118_相機標定/output/intrinsics_cam0.yaml）
- 沒有就寫「無」

## 檔案說明
| 檔案 | 用途 |
|------|------|
| main.py | ... |

## 執行方式
python main.py --參數 ...

## 輸出結果（供後續作業調用）
| 檔案 | 格式 | 內容 |
|------|------|------|
| output/xxx.yaml | OpenCV FileStorage | K、dist、R、t ... |

## 備註
遇到的問題、參數設定、拍攝條件等。
```
